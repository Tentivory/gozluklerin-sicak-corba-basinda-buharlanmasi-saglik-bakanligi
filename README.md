# gozluklerin-sicak-corba-basinda-buharlanmasi-saglik-bakanligi
Sıcak çorba başında gözlüklerin buharlanmasını resmi halk sağlığı olayı ve görme hakkı ihlali sayan, merceği vaka, buharı salgın, 'biraz üflersem açılır' cümlesini tedavi reddi ilan eden Bakanlık. Gerçekten çalışır. Gözlükler artık hastadır.
